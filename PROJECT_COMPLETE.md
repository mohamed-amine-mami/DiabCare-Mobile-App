## 🛠️ Customization Guide

### Change Primary Color
Edit `lib/theme/app_colors.dart`:
```dart
static const softGreen = Color(0xFF7DDAB9); // Your color here
```

### Add a New Screen
1. Create file in `lib/screens/`
2. Use existing screens as template
3. Import theme and widgets
4. Add to navigation

### Modify Components
Use `lib/widgets/diabcare_widgets.dart` for reusable components
